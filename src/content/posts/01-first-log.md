기술을 배울 때 가장 오래 남는 것은 직접 만들어 본 경험입니다. 코드를 작성하고, 예상과 다른 결과를 만나고, 이유를 찾아가는 과정을 이곳에 남기려 합니다.

## 만드는 과정 자체가 콘텐츠

DEV UNIVERSE는 완성된 결과만을 전시하는 공간이 아닙니다. 어떤 선택을 했는지, 무엇을 확인했는지, 다음에는 어떻게 바꿔 볼지를 기록하는 작업 노트입니다.

앞으로 웹 개발, 서버 운영, AI를 활용한 개발 흐름을 다룹니다. 짧은 실험도 하나의 글이 될 수 있습니다.

## 이 블로그의 구성

글은 Markdown 파일로 작성하고 GitHub에서 버전을 관리합니다. Astro가 각 글을 HTML로 빌드하면 VPS의 전용 웹 서버가 결과물을 제공합니다. 페이지를 읽기 위해 데이터베이스나 로그인은 필요하지 않습니다.

```text
Markdown → GitHub → Astro build → VPS → Reader
```

가벼운 구성으로 시작한 이유는 글을 쓰고 고치는 일에 집중하기 위해서입니다. 검색, 주제 필터, RSS는 읽는 사람에게 필요한 기본 기능으로 준비했습니다.

## 기록의 원칙

- 확인한 사실과 추측을 구분합니다.
- 실행 환경과 검증 범위를 함께 남깁니다.
- 민감한 정보와 개인 인증 정보는 공개하지 않습니다.
- 잘못된 내용은 수정하고 변경 이력은 남깁니다.

이제 첫 페이지가 열렸습니다. 작게 만들고, 깊이 이해하고, 꾸준히 기록하겠습니다.
